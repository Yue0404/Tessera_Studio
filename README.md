# 密铺地图工坊（Tessera Studio）

密铺地图工坊是一款用于在正六边形、正方形和正三角形密铺地图上绘制各种元素的网站应用。

> 当前项目尚处于初始化阶段，产品能力与技术实现正在逐步建立。

## 支持的网格方向

- 正六边形网格：适合策略游戏、桌游与区域地图。
- 正方形网格：适合传统棋盘、像素地图与规则布局。
- 正三角形网格：适合三角密铺图案与特殊空间关系设计。

## 核心编辑方向

- 创建和配置有限尺寸的密铺地图。
- 在网格单元上绘制颜色、图标、文字等地图元素。
- 提供选择、擦除、填充、撤销与重做等基础编辑能力。
- 支持工程的本地保存、再次编辑以及图片或矢量格式导出。

产品需求与设计细节目前保存在被 Git 忽略的本地 `docs/` 工作文档目录中，不随仓库提交。
