# 密铺地图工坊用户手册

## 1. 支持范围

密铺地图工坊面向 PC 桌面浏览器，支持正方形和尖顶正六边形有限地图。Safari、移动端和触控完整编辑不在当前发布范围。

网站无需账号。工程和扩展包保存在当前浏览器配置文件的站点数据中，不会自动同步到其他浏览器或电脑。

## 2. 新建与恢复工程

首次打开网站时，可以：

1. 输入工程名，选择正方形或尖顶六边形；
2. 设置宽、高、单元格尺寸和基础颜色；
3. 可选启用已安装且兼容的模块或预设；
4. 选择“创建工程”。

宽和高均须为 1–40000 的整数。空白工程始终启用 `tessera.basic`，无需 Civilization VI 或其他扩展包。

若浏览器中存在上次成功保存的工程，网站会在启动时恢复。正常“没有工程”不是错误；恢复失败时仍可新建或载入 Project 文件。

## 3. 编辑

- “选择”用于单选、Shift 多选和矩形框选；
- “画刷”支持绘制、擦除与连通填充；
- 边工具编辑共享边；
- 连接工具创建线和箭头；
- 内容工具放置文字和标记；
- 图层面板控制显示、锁定和透明度；
- 缩放控件、滚轮、平移工具、空格拖动或中键拖动用于导航。

锁定图层不能编辑；隐藏图层不会出现在画布或视觉导出中。撤销和重做只影响工程内容，不会改变文件系统中的旧备份。

## 4. 保存与工程文件

网站会把修改自动保存到浏览器本地存储，并显示未保存、保存中、已保存或保存失败状态。浏览器站点数据不是永久备份。

数据导出包括：

- **完整 Tessera Project**：包含当前工程全部图层和对象，包括隐藏内容，适合作为备份；
- **部分 Tessera Project**：按范围和图层导出为独立派生工程，并持续显示来源省略状态；
- **Tessera Fragment**：用于把部分内容原子合并到另一个兼容工程。

载入完整 Project 时，如本地已有相同工程 ID，默认安全动作是“作为副本打开”；只有明确确认后才替换本地工程。载入 partial 始终生成新的工程 ID。

## 5. Fragment 合并

Fragment 与当前工程必须具有兼容的网格、单元格尺寸、精确模块版本和固定图层。越界时可输入整体平移量后重新检查；确认合并前不会修改工程。合并、保存或验证失败时保留原工程。

## 6. PNG 与 SVG

图片导出支持：

- 当前视口、最近框选、自定义矩形、内容范围和整图范围；
- PNG 的 1×、2×、4×；
- 透明或指定 RGBA 背景；
- 显示或隐藏系统网格；
- PNG 和 SVG。

导出任务超过短时阈值会显示进度，可取消。若范围、倍率、图元或浏览器画布能力超限，请按错误提示缩小范围、降低倍率、分块导出或改用 SVG。

## 7. 扩展包

“包设置”使用同一通用加载器导入 `.tessera-module.zip` 与 `.tessera-preset.zip`。导入会在写入前完成路径、大小、格式、依赖、资源和浏览器解码验证。

缺失或不兼容模块的工程内容会保留为锁定的只读占位；重新安装精确版本后可恢复编辑。删除当前工程依赖的包前会再次确认。

Civilization VI 是可选模块。网站不会扫描游戏目录、自动下载或运行提取器；用户必须主动选择已有模块包。提取器下载入口只在受跟踪目录含真实 Release 信息时显示。

## 8. 浏览器与隐私

网站不会上传工程、扩展包或游戏资源。清除站点数据、浏览器配置文件损坏、隐私模式结束或磁盘故障都可能删除本地数据，因此请遵循[备份与恢复说明](BACKUP_AND_RECOVERY.zh-CN.md)。
