# 备份与恢复

## 备份原则

浏览器中的 IndexedDB/OPFS 只用于本地恢复，不是永久备份。建议在重要编辑后下载“完整 Tessera Project”，并把文件复制到浏览器配置目录之外。

扩展包不会嵌入 Project。若工程依赖用户扩展包，还应分别保存安装时使用的精确版本归档。Civilization VI 本地生成包不得上传到项目仓库或网站。

## 创建可恢复备份

1. 等待保存状态显示“已保存”；
2. 选择“导出”→“数据导出”；
3. 选择“完整 Tessera Project”；
4. 下载并保留 `.tessera-project.json`；
5. 对重要版本使用不同文件名或外部备份工具保存。

部分 Project 和 Fragment 不能替代来源完整工程的备份。partial 导出为 full 后，只表示完整包含当前派生工程，不能恢复来源中已省略的内容。

## 恢复顺序

1. 正常刷新页面，确认网站能恢复最近一次成功自动保存；
2. 若启动恢复失败，先不要清除站点数据，可直接载入最近的完整 Project 文件；
3. 若提示模块缺失，工程应以只读占位打开；安装精确模块版本后再恢复编辑；
4. 同 ID 冲突时先选“作为副本打开”，确认内容正确后再决定是否替换；
5. 文件损坏或不兼容时保留当前工程，并改用上一份备份。

## 保存失败

保存失败可能来自浏览器配额、IndexedDB/OPFS 故障、磁盘空间不足或浏览器权限变化。失败不会把半写入修订切换为当前版本，但尚未成功保存的编辑可能在关闭页面后丢失。

处理建议：

- 立即导出完整 Project；若导出也失败，先保持页面开启；
- 释放磁盘空间并重试保存；
- 不要在未确认备份前清除站点数据；
- 记录浏览器名称、精确版本、错误提示和操作步骤。

## 清除站点数据的影响

清除当前站点数据会删除浏览器内的工程修订、已安装扩展包和授权状态。它不会删除用户已下载到文件系统的 Project、Fragment、图片或扩展包归档。

## 故障报告最小信息

- 操作系统和浏览器精确版本；
- 工程网格、尺寸与大致对象数量；
- 保存状态和可见错误文案；
- 是否仍能导出完整 Project；
- 可安全分享时提供去除私密内容的最小复现文件。

不要提交 Civilization VI 游戏文件、本地生成图片或含个人路径的日志。
